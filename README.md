# ravi-writes-abinitio-to-spark

Runnable notebooks that accompany the **Ab Initio → PySpark** notes at
**[ravi-writes.pages.dev](https://ravi-writes.pages.dev/notes/abinitio-to-pyspark/core-operations/)**.

Each notebook is self-contained — it builds its own tiny DataFrame with
`createDataFrame` (no data files to download) and installs PySpark in its first
cell, so it runs top-to-bottom in Google Colab with nothing installed locally.

| Notebook | Note |
| --- | --- |
| [`filter.ipynb`](filter.ipynb) | [filter / where](https://ravi-writes.pages.dev/notes/abinitio-to-pyspark/core-operations/filter) |

Click the **Open in Colab** badge on any note to launch its notebook.
